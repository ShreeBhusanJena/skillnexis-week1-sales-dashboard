# skillnexis-week1-sales-dashboard
Skill Nexis Week 1 Excel Sales Dashboard Project

## Sales Analysis Dashboard

### About the Project

This project was completed as part of the Skill Nexis Data Analyst Internship – Week 1. The objective is to analyze sales data using Microsoft Excel and present key business insights through an interactive dashboard.

### Tools Used

* Microsoft Excel
* Pivot Tables
* Data Cleaning
* Charts and Data Visualization
* Descriptive Statistics

### Key Analysis

* Total Revenue
* Sales by Category
* Yearly Sales Trends
* Subcategory-wise Revenue
* Total Profit and Units Sold

### Project File

The Excel workbook contains the sales analysis dashboard, charts, and summarized data.
